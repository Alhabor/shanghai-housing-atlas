# 住房研究综合图谱

这是位于选区研究和租赁市场研究之上的独立展示层。它把相同地铁站的通勤、租赁状态、严格步行半径、代表小区与已核验房源放在同一个界面中。

“房源样本 / Listing samples”视图只显示完成详情抽样的四个站点。第三轮扩样后共纳入34套当前房源：地图标记落在已核验的百度小区POI，标签同时显示小区名、百度步行距离、样本数量和通过/待确认/失败构成；点击小区会展开逐套价格并联动高亮右侧卡片。右侧逐套展示主图、整套月租、两人均分参考、预算层级、面积、楼层、电梯、可入住时间、房况观察及贝壳原页。

贝壳挂牌页没有提供可可靠复用的具体楼栋或门牌坐标，因此地图定位精度明确限定为“小区POI”。页面不把同一小区的多套样本抖动成虚假的楼栋点，也不把小区到站的直线画成实际步行路线。

页面的站点标签、地图标记、顶部统计和详情主徽章统一采用当前视图的状态口径：综合视图显示纳入第三轮房源复核后的结论，通勤视图显示通勤等级，区域市场视图显示第一轮租赁红黄绿，房源样本视图显示最新微观结论。

## 打开

直接打开 `index.html`。页面使用本目录的Leaflet、地铁几何和研究快照；联网时加载OpenStreetMap底图。

## 独立性

- 页面运行时不读取 `area_research/` 或 `rental_market_research/`。
- `data/research-snapshot.json` 是便于审计的格式。
- `assets/research-snapshot.js` 是供本地HTML直接读取的同一份快照。
- 两个专项研究仍是事实来源；综合层不反向修改它们。

## 更新快照

当专项研究数据改变后，在工作区根目录运行：

```bash
python3 housing_research_atlas/tools/update-snapshots.py
```

脚本只在更新时读取两个来源项目，生成后的页面仍可独立运行。
